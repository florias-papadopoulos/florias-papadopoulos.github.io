# florias-papadopoulos.github.io

Personal website, built with [Hugo](https://gohugo.io) and the
[hugo-website](https://github.com/pmichaillat/hugo-website) template (PaperMod based).

- Home page text, menu and links: `config.yml`
- Projects: one Markdown file per project in `_pages/projects/` (files next to it);
  the list page text is in `content/projects/_index.md`
- CV: `files/resume.pdf`
- Games: `games/` is generated by `CryptoGames/tools/build.py` (encrypted content only)

Preview locally: `hugo server`, then open http://localhost:1313.

Deployment: GitHub Actions (`.github/workflows/hugo.yml`) builds and publishes on every push
to `master`. In the repository settings, Pages must use "GitHub Actions" as the source.
